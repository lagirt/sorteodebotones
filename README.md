# Elige tu destino (`sorteodebotones`)

Aplicación sencilla en HTML, CSS y JavaScript donde el usuario elige entre dos botones grandes (uno rojo y uno azul) para descubrir de forma aleatoria si ha ganado o ha perdido.

## Características
- **Título**: `"Elige tu destino"`
- **Dos botones grandes**: uno **rojo** y uno **azul**
- **Mensaje aleatorio**: muestra `"Has ganado"` o `"Has perdido"` al hacer clic
- **Botón `"Volver a jugar"`**: reinicia la partida para intentarlo de nuevo
- **Diseño limpio y centrado**: adaptable a cualquier pantalla

## Archivos del proyecto
- `index.html`: Estructura de la aplicación
- `styles.css`: Diseño limpio, centrado y estilos de los botones rojo y azul
- `script.js`: Lógica del sorteo aleatorio y reinicio del juego
